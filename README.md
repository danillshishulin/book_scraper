# Парсер книг (Book Scraper)

## Что делает
Программа заходит на тренировочный сайт, скачивает страницу, находит информацию с названиями и ценами книг, предоставляет её в виде таблицы и дополнительно Excel-файла.

## Возможности программы
- Скачивание HTML-страницы через библиотеку requests
- Поиск нужных данных через BeautifulSoup
- Сбор названий и цен
- Сохранение результата в файл books.xlsx

## Технологии
- Python 3
- requests
- BeautifulSoup4
- pandas
- openpyxl (для Excel)

## Запуск
- Для запуска импортируем все необходимые нам библиотеки: pandas, requests, bs4
- Сохраняем таблицу в Excel-файл
- Запускаем скрипт
